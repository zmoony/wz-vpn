# 项目背景

- 项目名称：Pi-Gateway。
- 当前仓库阶段：从纯文档仓库进入首轮代码落地。
- 部署目标：宿主机原生安装 + systemd 管理，不使用 Docker。
- 本轮实现范围：前后端完整骨架；真实能力优先实现登录鉴权、系统状态、WireGuard peer 管理；其余模块保留页面与 API 骨架。
- 技术方向：Go 后端 + Vue3 前端 + SQLite；发布形态为后端托管静态前端资源。

# 当前约束

- 用户本地没有可直接用于集成测试的目标环境。
- 当前终端可用 `node`/`npm`，但 `go` 不在 PATH 中。
- 需要保持最小改动原则，同时为后续 DDNS / nginx / nftables 扩展留出稳定边界。
