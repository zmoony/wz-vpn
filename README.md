# Pi-Gateway

> 树莓派家庭服务器网关套件 —— 参考 [lucky666.cn](https://lucky666.cn) 的设计理念，自主可控、面向 IPv6-only 公网环境优化。

## 一句话介绍

在树莓派上跑一套统一的网关：把"该公开的服务安全公开（DDNS + SSL + 反代）"和"不该公开的服务通过 VPN 远程接入"这两件事，加上防火墙可视化配置，用一个自研 Web 管理面板统一管起来。

## 核心特性概览

| 类别 | 能力 |
|---|---|
| 公网入口 | DDNS（阿里云 AAAA 自动更新）、Nginx 反向代理、Let's Encrypt 泛域名证书自动续期 |
| 远程接入 | WireGuard VPN，远程拨入家庭内网，访问所有不暴露公网的服务 |
| 防火墙 | 基于 nftables 的可视化防火墙：区域 / 服务 / 端口 / 来源 IP 白名单，IPv4 + IPv6 双栈 |
| 网络兜底 | 默认对接 Cloudflare Tunnel 解决 IPv6-only 对 IPv4 客户端不可达问题 |
| 统一管理 | 自研 Web 管理面板（Go + Vue3），登录鉴权、可视化配置、状态总览、温度监控 |
| 部署形态 | **宿主机原生安装 + systemd 管理**（无 Docker），管理面板单二进制（ARM64） |

## 运行环境

- 硬件：Raspberry Pi 4 / 5（ARM64）
- 系统：Raspberry Pi OS Bookworm 64-bit（Debian 12）
- 网络：IPv6 公网 + IPv4 大内网
- 域名：阿里云
- 部署：**不使用 Docker**，全部 apt 安装 + systemd 管理
