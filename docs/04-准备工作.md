# Pi-Gateway 部署前准备工作

> 本文档列出开工部署前用户需要自行准备的所有事项，按"必备 / 可选 / 推荐"分级。

---

## 1. 必备项（缺一不可）

### 1.1 树莓派硬件
- [ ] Raspberry Pi 4 (≥ 2GB) 或 Raspberry Pi 5
- [ ] 至少 16GB 的 SD 卡（推荐 32GB，A1 等级以上）
- [ ] 稳定电源（5V/3A 官方电源）
- [ ] 网线连接到家里路由器（**强烈不建议用 WiFi**）
- [ ] 推荐：**外置 SSD/U盘** 用于挂 `data/` 目录，延长 SD 卡寿命

### 1.2 操作系统
- [ ] 已刷好 **Raspberry Pi OS Bookworm 64-bit**（或 Debian 12 ARM64）
- [ ] 已配置可 SSH 登录（默认用户 `pi` 或自定义）
- [ ] 已执行 `sudo apt update && sudo apt upgrade -y`
- [ ] **不需要安装 Docker**（本项目全部宿主机原生运行）

### 1.3 网络环境
- [ ] 家里宽带已开通 **公网 IPv6**（电信、移动、联通均默认开启，可去运营商 App 确认）
- [ ] 光猫/路由器已经把 IPv6 防火墙**允许树莓派入站**
- [ ] 测试方法：在树莓派上执行 `curl -6 ifconfig.co` 能返回非 fe80 / fd 开头的全球地址

### 1.4 域名
- [ ] 在 **阿里云** 已购买一个域名（建议 `.com` / `.cn` / 也可以是几块钱的便宜后缀）
- [ ] 域名已经实名认证通过
- [ ] 已在阿里云 DNS 控制台看到该域名

### 1.5 阿里云 AccessKey
按以下步骤准备**子账号 AK**，**不要用主账号 AK**：

1. 登录阿里云 → RAM 访问控制 → 创建用户（不勾"控制台访问"，只勾"OpenAPI 调用访问"）
2. 给用户授予系统权限：`AliyunDNSFullAccess`
3. 创建该用户的 AccessKey，把 `AccessKey ID` 和 `AccessKey Secret` 妥善保存

> 这两个值非常敏感，**不要写到 git 仓库、不要发到群里**。部署时通过配置文件或面板加密存储。

---

## 2. 推荐项（强烈建议有）

### 2.1 Cloudflare 账号（IPv4 兜底用）
- [ ] 注册 [cloudflare.com](https://www.cloudflare.com) 免费账号
- [ ] 用途：当外出网络是 IPv4-only 时，通过 Cloudflare Tunnel 仍能访问家里的 Web 服务
- [ ] 准备阶段不需要做配置，**部署阶段会引导**

### 2.2 外置存储
- [ ] 一块 USB SSD（建议 SATA 转 USB3.0，128GB+）
- [ ] 挂载到 `/mnt/data`，把 `pi-gateway/data` 软链或直接放到那里
- [ ] 避免 SD 卡因频繁写入挂掉

### 2.3 备份策略（先想好）
- [ ] 至少每周一次 `data/` 目录冷备份（可手动 / 后续自动）
- [ ] 备份位置：另一台电脑 NAS / 云盘 / Cloudflare R2

---

## 3. 可选项

### 3.1 自购轻量 VPS（如果想让 VPN 也能从 IPv4 网络拨入）
- [ ] 阿里云轻量 / 腾讯云轻量 / Vultr / Racknerd 等
- [ ] 配置：1c1g 即可，重点是**有公网 IPv4 + 较低延迟**
- [ ] 国内 VPS 优先选**境内运营商优质线路**节点
- [ ] 预算：约 30–80 元/年

### 3.2 监控告警通道
- [ ] Telegram Bot Token（如果想要 TG 通知）
- [ ] [Bark](https://github.com/Finb/Bark) 推送 Key（iOS 用户推荐）

### 3.3 自定义 favicon / Logo
- [ ] 给面板换个自己喜欢的图标和名字（v1 默认即可）

## 4. 提交清单（部署前确认）

在我们开始正式部署前，用户应当能填好下面这份"开工信息表"：

```yaml
# === 必填 ===
device:
  os: "Raspberry Pi OS Bookworm 64-bit"   # 或 Debian 12
  ssh_user: ""                             # 你的 SSH 用户名
  ssh_host: ""                             # 树莓派局域网 IP

domain:
  root: "example.com"                      # 你买的域名
  records:                                 # 想用的子域名（可后续追加）
    - "home"                               # home.example.com 用于 DDNS / 反代 host
    - "vpn"                                # vpn.example.com 用于 WG 客户端 Endpoint
    - "blog"                               # 暴露的博客示例

aliyun:
  access_key_id: ""                        # 阿里云子账号 AK ID
  access_key_secret: ""                    # 阿里云子账号 Secret

admin:
  username: "admin"                        # 管理面板用户名
  password: ""                             # 初始密码（建议 12 位以上）

# === 可选 ===
cloudflare:
  enabled: true
  api_token: ""                            # 留空则部署时引导扫码

vps_relay:
  enabled: false                           # 是否要 VPS 中转给 IPv4 VPN 客户端
  host: ""
  port: 0
```

## 5. 安装脚本会自动完成的事

用户只需准备好上面 1.1 ~ 1.5 的硬件和账号，安装脚本会自动：

1. `apt install nginx wireguard nftables curl socat`
2. 下载 ddns-go ARM64 二进制
3. 安装 acme.sh
4. 下载 pi-gateway 管理面板二进制
5. 生成 systemd unit 文件
6. 初始化 nftables 默认安全规则
7. 生成 WireGuard 服务端密钥 + wg0.conf
8. 启动所有服务并设置开机自启

---

## 6. 进入下一阶段的准入条件

当上面 1.1 ~ 1.5 全部准备好，且 4. 中**必填项**填完，即可进入"systemd 基线 + 管理面板骨架"开发阶段。

缺哪一项就先补哪一项，**不要硬上**。
