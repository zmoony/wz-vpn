# Pi-Gateway 功能清单（开发待办源）

> 按优先级 P0 / P1 / P2 划分；每条会作为开发阶段的工作项。

---

## 优先级定义

- **P0 必做**：v1.0 验收不可缺少；用户口中"核心功能"
- **P1 重要**：v1.0 应当具备，但单独缺一项不阻碍上线
- **P2 增强**：v1.x 迭代加入；不影响 v1.0 验收

---

## P0 必做（v1.0 核心）

### F-DDNS-01 IPv6 DDNS 自动更新
- ddns-go 作为 systemd 服务运行
- 定时（默认 5 分钟）检测当前公网 IPv6
- 与上次记录值对比，变化则调用阿里云 OpenAPI 更新 AAAA
- 失败重试（指数退避，最多 3 次）
- 记录每次更新结果，面板可查

### F-CERT-01 Let's Encrypt 证书自动签发
- acme.sh 宿主机安装（`~/.acme.sh/`）
- 通过阿里云 DNS-01 验证
- 默认申请 `*.example.com` 泛域名 + `example.com` 顶级
- 申请成功后安装到 `/opt/pi-gateway/data/certs/` 并 reload nginx

### F-CERT-02 证书自动续期
- systemd timer（`acme-renew.timer`）每日 0:00 检查
- 剩余 < 30 天则续期
- 续期成功执行 `nginx -s reload`
- 失败提前 20 天面板告警

### F-PROXY-01 反向代理配置 CRUD
- 管理面板直接生成 nginx vhost 文件（`/etc/nginx/sites-enabled/*.conf`）
- 列出所有反代主机
- 新增：子域名、后端 IP/Port、绑定证书、启用开关
- 编辑、删除、启用/禁用
- 每次变更：`nginx -t` 校验 → 通过则 `nginx -s reload` → 不通过则回滚文件

### F-WG-01 WireGuard 服务端基础部署
- `apt install wireguard` 宿主机安装
- 自动生成服务端密钥对
- 默认配置：`wg0`、UDP 51820、`10.66.66.1/24`
- 开启 IP 转发 `net.ipv4.ip_forward=1`、IPv6 同步
- `systemctl enable wg-quick@wg0` 开机自启

### F-WG-02 WireGuard 客户端 peer 管理
- 列表：名称、IP、最后握手、收发流量、是否在线
- 新增：填名称 → 自动分配 IP → 生成 keypair → 输出 conf + 二维码
- 删除：立即 `wg set wg0 peer <pub> remove` 生效
- 启用/禁用：临时 remove，不删除配置

### F-FW-01 防火墙可视化管理
- 底层：nftables（`apt install nftables`，Debian 12 默认可用）
- **区域概览**：公网入站 / VPN 入站 / 转发 三个区域
- **服务模板**：预置 SSH / HTTP / HTTPS / WireGuard / DNS 等常见服务，一键放行
- **自定义规则**：协议、端口（单个/范围）、来源 IP/网段（IPv4 + IPv6 双栈）
- **启用/禁用**：单条规则可临时禁用
- **规则排序**：拖拽调整优先级
- **实时预览**：修改后先预览最终 nft 规则文本，确认再应用
- **安全锁**：应用后 30 秒内未确认自动回滚

### F-FW-02 防火墙默认规则集
- input 默认 `drop`
- 默认放行：lo / icmpv6(NDP 必须) / established,related / SSH / WireGuard / HTTP / HTTPS
- forward：允许 wg0 → eth0

### F-AUTH-01 管理员登录
- 账号 + 密码（bcrypt 哈希，cost ≥ 12）
- JWT via HttpOnly Cookie
- 安装脚本首次设置密码

### F-UI-01 管理面板基本骨架
- 登录页
- 左侧菜单 + 顶部状态栏
- Dashboard 首页（系统状态 + 各模块概要）
- 反代、VPN、防火墙、证书、DDNS、系统设置子页

### F-SYS-01 系统状态采集
- CPU 使用率、负载
- 内存使用率
- 树莓派核心温度
- 磁盘使用率
- 各网卡收发流量
- WebSocket 每 2 秒推送

### F-DEPLOY-01 一键安装脚本
- 检测系统版本（Debian 12 / Pi OS Bookworm）
- `apt install nginx wireguard nftables` 等依赖
- 下载/编译 pi-gateway 二进制
- 下载 ddns-go 二进制
- 安装 acme.sh
- 创建 systemd unit 文件（ddns-go / pi-gateway / acme-renew.timer）
- 生成初始 nftables 规则
- 交互式输入初始管理员密码、阿里云 AK、域名

## P1 重要（v1.0 应当具备）

### F-DDNS-02 多记录支持
- 一个域名下多个子记录的 AAAA 同步
- 自定义 TTL

### F-CERT-03 证书面板
- 列表展示：域名、过期时间、剩余天数、颁发机构
- 一键强制续期
- 上传第三方证书（手动场景兜底）

### F-WG-03 客户端可视化辅助
- 二维码弹窗带"下载 .conf"按钮
- "复制配置到剪贴板"
- 配置预览（带客户端 Endpoint 自动填充 DDNS 域名）

### F-FW-03 活跃连接列表
- 读取 conntrack 表展示活跃连接
- 可按来源 IP / 目标端口 / 协议筛选
- 一键 block 某个来源 IP

### F-SYS-02 温度告警
- 阈值可配置（默认 75°C）
- 面板顶部红色横幅
- 一键查看历史趋势图（近 1 小时）

### F-SVC-01 服务导航页
- 用户登记内网服务（名称、URL、图标、是否公开）
- 类 Homepage 卡片式展示
- 一键跳转

### F-AUDIT-01 操作审计
- 关键操作（增删改反代、增删 peer、防火墙变更）写入审计表
- 面板可查最近 100 条

### F-IPV4-01 Cloudflare Tunnel 集成（可选模块）
- 引导式接入：填 Cloudflare API Token 或扫码登录
- 选择要走 Tunnel 的域名
- cloudflared 作为 systemd 服务运行

### F-DEPLOY-02 升级脚本
- `update.sh` 一键升级
- 备份当前 data 目录
- 下载新版二进制 / apt upgrade 依赖
- 失败回滚

## P2 增强（v1.x 后续）

### F-PROXY-02 高级反代选项
- WebSocket、HTTP/2、HSTS、Cache、自定义 Nginx Location 片段

### F-PORT-01 TCP/UDP 端口透传
- 非 HTTP 场景（如游戏服务、SMTP）
- 基于 nginx stream 模块

### F-FW-04 防火墙规则导入/导出
- 导出当前规则为 nft 文件或 JSON
- 导入规则文件

### F-FW-05 GeoIP 封禁
- 按国家/地区 block 来源 IP（需 geoip 数据库）
- 适合防扫描

### F-LOG-01 日志聚合
- nginx 访问日志（可筛选域名/状态码）
- WG 连接日志
- nftables 日志（被 drop 的连接记录）
- 全文检索（小规模，sqlite FTS5）

### F-AUTH-02 TOTP 二次验证
- 绑定 Authenticator
- 备份恢复码

### F-BAK-01 配置备份/恢复
- 一键打包 data 目录为 tar.gz
- 上传到对象存储（可选 Cloudflare R2 / 阿里云 OSS）
- 一键恢复

### F-NOTIFY-01 告警通知
- Telegram Bot / Bark / 邮件
- 触发条件：证书续期失败、温度过高、磁盘满、DDNS 失败、防火墙异常

### F-WG-04 多 WG 接口
- 支持 wg0 / wg1 不同网段，做分组隔离（如家人专用网段）

### F-METRICS-01 历史指标存储
- sqlite 时序存储或外接 VictoriaMetrics 单机版
- 趋势图扩展到近 24 小时 / 7 天

### F-I18N-01 国际化
- 中英文切换
